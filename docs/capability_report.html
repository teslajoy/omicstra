MCP surface

22 tools, 4 resources, stdio + HTTP (stateless, streamable). zero server-side model calls. the client model (Claude Desktop, Claude Code, or any MCP client) interprets questions; the server validates, computes and returns.

transport

stdio and HTTP are the same server. HTTP is stateless - any instance handles any request. run handle (run_id) is an ordinary parameter, no sticky session. protocol negotiation: MCP 2026-07-28 (july revision, OAuth 2.1 resource server); REQUIRE_PROTOCOL_2026=1 refuses older clients.

decision architecture (no server-side model)

  • route resolves by deterministic rule over measured evidence (recommend / tie / escalate / refuse)
  • evaluate_run / evaluate_measure compute verdicts (biological / diagnostic / unguarded / not_run) from guards and permutation statistics
  • ask validates and executes, returns findings + provenance

synthesis (drawing conclusions across hypotheses, writing the narrative) happens on the client model, not in the server. there is no server-side "judge" or "brain" agent.

de-novo clustering for ground truth

cohorts without supplied annotations need de-novo niche-type labels for evaluation. the evaluation chain requires an h2_label (niche-type classification) and a supervision signal. a de-novo labeling protocol produces these from the cohort's own embeddings. open_items #48, links to WS 4 + WS 7.

de-novo labeling protocol not built
level
level 2 protocol (fixed method, no state, no interrupt). callable from a notebook
inputs
an embedding already on disk (molecular or morphological niche vectors), a resolution parameter (analytical binding, layer 3), a minimum cluster size (method constraint)
method
leiden clustering on the encoder's niche embeddings
output
a per-niche integer label column, declared as h2_label in the cohort's project.json. the existing evaluation chain scores against it identically to a supplied label - the binding is different, the chain is the same
where
protocols/ as a level 2 step chain. the binding that selects it is layer 3 (WS 4). the protocol itself is WS 7

why these choices

molecular encoder
the graph attention network learns per-edge attention weights over the spatial graph, so its latent space already encodes spatial co-expression structure. no separate spatial graph construction or spatial-vs-feature weighting needed - clustering its output directly produces niche types that reflect both expression and spatial context
morphological encoder
the niche embedding (mean over k+1 tiles within the niche footprint) captures local tissue architecture through the tiling geometry. clustering it produces morphology-derived niche types without pathologist annotation
leiden
guarantees connected communities - every member has a path to every other member through the community subgraph. louvain can produce internally disconnected clusters. resolution is the only free parameter and is declared as a binding

validation on the seed cohort

  • run leiden at several resolutions on both encoder outputs
  • compare against the 6 existing labels (14-class NMF, 17 morphological categories, TLS signature, TIME, patient_id, spatial archetypes) using ARI, NMI and homogeneity
  • de-novo labels should recover niche-level biology (correlate with NMF and morphological categories) and not patient identity (low NMI against patient_id)
  • this comparison is a notebook, not a gate - it calibrates the method rather than blocking it
