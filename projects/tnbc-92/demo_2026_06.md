## 1. what omicstra does and why

### the problem

H&E histopathology and spatial transcriptomics measure different aspects of the same tissue. A pathologist sees morphology. ST measures gene expression with spatial coordinates. Both are anchored to the same physical locations - but their representations live in completely different embedding spaces with no shared coordinate system.

**Question**: can we build a shared representation space where morphological features and transcriptomic features are directly comparable - and does that shared space preserve real biology?

### the approach

```
H&E image                              spatial transcriptomics
    |                                           |
    v                                           v
Virchow2 (1280d)                    Novae GNN (64d) + gpath2vec (512d)
    |                                           |
    v                                           v
  MLP_he                                     MLP_st
    |                                           |
    v                                           v
  z_he (512d, L2-normed)             z_st (512d, L2-normed)
    |                                           |
    +------------ InfoNCE loss ----------------+
              "pull matched pairs together,
               push mismatched pairs apart"
```

The contrastive loss says: for each tissue niche, the H&E embedding and ST embedding of the **same** niche should be more similar than embeddings of **different** niches.

### the dataset

Wang et al. 2024. 92 TNBC patients, co-registered H&E whole-slide images + spatial transcriptomics.

| property | value |
|---|---|
| patients | 94 on disk (92 in publication, IDs 17/18 QC-failed) |
| subarrays | 260 matched (H&E + ST) |
| niches (v3 niche-join) | 208,786 (each = center spot + 6 spatial neighbors) |
| test set | 14 patients, 38 subarrays, 35,594 niches |
| split | patient-stratified 85/15, seed=42 |
| platform | original Spatial Transcriptomics (Stahl 2016), NOT 10x Visium |

## 2. data and encoders

### encoder selection was empirical, not assumed

We ran a head-to-head comparison of foundation models on this specific tissue.

| encoder | what it encodes | dimension | MC linear probe | chosen? |
|---|---|---|---|---|
| Virchow2 (MSK, 632M params) | H&E morphology at niche scale | 1280d | 23.6% (3.3x chance) | **yes - primary** |
| UNI2-h (Mass General, 681M) | H&E morphology at spot scale | 1536d | lower on MC task | no - alternative |
| Novae GNN (MICS-Lab, 32M) | ST spatial neighborhoods | 64d | 12.1% (1.7x chance) | **yes - validated with caveats** |
| gpath2vec (ours) | Reactome pathway walks | 512d | n/a | **yes - v3 build canonical** |

**Why Virchow2 over UNI2**: On a 14-class niche-level megacluster classification task (linear probe, patient-stratified), Virchow2 niche pooling outperformed UNI2 variants. This matches the PathoROB benchmark (Komen 2025) finding that Virchow2 is Pareto-optimal for robustness across stain variation.

**Novae caveat**: Novae was trained on MERSCOPE/Xenium/CosMX (subcellular resolution, ~0.5 um). Our data is original ST platform (200 um spot spacing) - a 400x scale mismatch in spatial resolution. Despite this, Novae's spatial autocorrelation on our data (Spearman rho = -0.38) is comparable to Virchow2 (-0.41), confirming it captures local spatial structure even out-of-distribution. But only 11 of its 64 dimensions carry meaningful variance - this is the information bottleneck of the ST side.

## 3. alignment architecture

### the 10-run grid

We tested 6 contrastive methods + 4 baselines, all on the same data split:

| run | loss function | architecture | ST input | what it tests |
|---|---|---|---|---|
| **R1** | InfoNCE | late fusion (independent MLPs) | novae + gpath2vec (576d) | CLIP-style contrastive baseline |
| **R2** | SupCon | late fusion | novae + gpath2vec | soft supervision from NMF mc_weights |
| **R3** | Barlow Twins | late fusion | novae + gpath2vec | redundancy-reduction, no explicit negatives |
| **R4** | InfoNCE | **cross-attention** | novae + gpath2vec | ST queries attend over 7 raw H&E tile tokens |
| **R5** | AnInfoNCE | late fusion | novae + gpath2vec | per-dim learnable temperature (v3 addition) |
| **R6** | InfoNCE | late fusion | **novae only (64d)** | ablation: what happens without pathway input? |
| **B1** | CCA | linear, closed-form | - | classical baseline |
| **B2** | Procrustes | orthogonal rotation | - | classical baseline |
| **B3** | unaligned PCA | independent per-modality | - | sanity floor |
| **B4** | none (random init) | R1 architecture, no training | - | chance anchor |

**The key architectural difference** is R4. In late fusion (R1-R3, R5-R6), each modality is mean-pooled then projected independently. In R4's cross-attention, the ST embedding *queries* across 7 raw H&E tile tokens (center spot + 6 spatial neighbors at full Virchow2 1280d resolution) and selects which morphological features matter for each niche. This preserves tile-level detail that mean-pooling destroys.

## 4. H1 - does alignment work?

### verdict: yes. contrastive methods cleanly beat all baselines.

| run | AUC [95% CI] | CKA [95% CI] | median rank | gap |
|---|---|---|---|---|
| **R4 cross-attn** | **0.859 [0.857, 0.862]** | **0.631 [0.626, 0.636]** | **3,282** | **+0.233** |
| R1 late | 0.761 [0.758, 0.764] | 0.312 [0.305, 0.318] | 6,234 | +0.194 |
| R5 AnInfoNCE | 0.761 [0.758, 0.764] | 0.314 [0.306, 0.320] | 6,268 | +0.216 |
| R6 novae-only | 0.737 [0.734, 0.740] | 0.239 [0.233, 0.245] | 7,015 | +0.154 |
| R2 SupCon | 0.725 [0.722, 0.728] | 0.101 [0.098, 0.105] | 7,729 | +0.036 |
| B2 Procrustes | 0.706 [0.703, 0.710] | 0.125 [0.122, 0.129] | 8,069 | +0.161 |
| R3 Barlow | 0.674 [0.671, 0.677] | 0.306 [0.299, 0.312] | 7,643 | +0.143 |
| B1 CCA | 0.544 [0.541, 0.547] | 0.076 *(CI n/a)* | 15,554 | +0.007 |
| B4 random init | 0.496 [0.493, 0.499] | 0.120 [0.117, 0.124] | 17,936 | -0.000 |
| B3 unaligned PCA | 0.440 [0.437, 0.443] | 0.125 [0.122, 0.129] | 20,688 | -0.053 |
| *chance* | *0.500* | - | *17,797* | *0* |

> **methods.** AUC 95% CI: Hanley & McNeil (1982) closed-form (matched to bootstrap within 3 decimals); n_pos = 35,594, n_neg = 355,940 (10:1 sampled). CKA 95% CI: nonparametric bootstrap over test niches, B = 200, seed = 42. B1 CKA CI is not estimable by standard bootstrap because CCA's near-diagonal cross-covariance structure produces a structurally upward-biased bootstrap distribution; the point estimate is correct. computed by `scripts/eval_h1_bootstrap_ci.py`; raw arrays for ROC / PR / cosine-distribution plots persist in each run's `h1_eval_data.npz`.

### how to read this table

- **AUC 0.859** means: pick a random matched H&E-ST niche pair and a random mismatched pair. 85.9% of the time, the matched pair has higher cosine similarity. This is the probability that alignment *orders* correctly.
- **CKA 0.631** means: the overall pairwise-similarity structure of the H&E manifold and the ST manifold are 63% aligned after R4 projection (vs 11% before any alignment).
- **B4 at 0.496 (chance)** proves the architecture alone does nothing - contrastive *training* is what creates the alignment.
- **5 of 6 R-runs cleanly beat every classical baseline on AUC.** R4, R1, R5, R6, R2 each sit above the strongest classical (B2 Procrustes 0.706 [0.703, 0.710]) with non-overlapping 95% CIs. R3 Barlow Twins (0.674 [0.671, 0.677]) is the one contrastive run that sits below B2 - non-overlapping CI gap of 0.026. the families do not separate cleanly on the R3 / B2 boundary.

### the honest caveat

Absolute R@1 across ALL runs is ~0.0002 (chance ~0.00002). That is 10x above chance but still means only 1 in 5,000 queries finds its exact cross-modal match in the top position. At 35,594 test niches across 14 patients, exact niche-level cross-patient retrieval is near-impossible. What the alignment *can* do is rank matched pairs above mismatched pairs with high reliability (AUC). What it *cannot* do is production-grade "find the needle" retrieval at niche resolution.

## 5. H2 - does it preserve biology?

### part A - the archetype trap (a construct-validity story)

The proposal said: test whether the 9 spatial archetypes cluster more coherently in the aligned space.

**What we found**: archetypes are patient-level labels. Every niche in a patient inherits one archetype (NMI with patient_id = 0.89). "Archetype ARI" is a patient-classification test in disguise. B1 CCA wins by amplifying patient identity 3.3x - not by encoding biology.

| what it looks like | what it actually is |
|---|---|
| "B1 CCA best preserves spatial archetypes" | B1 CCA best classifies patients |
| "R4 worst on archetype coherence" | R4 suppresses patient identity most aggressively |

**The fix**: use Wang's per-spot 14-class `mc_megacluster` label (NMF on expression, varies at niche resolution, biology-derived). On the corrected label:

| run | KMeans ARI (mc) | linear probe accuracy | what it means |
|---|---|---|---|
| R5 AnInfoNCE | 0.246 | - | top cluster geometry |
| R6 novae-only | 0.244 | 0.276 | wins parsimony (no gpath2vec needed) |
| R1 late | 0.234 | 0.282 | top linear decodability |
| R4 cross-attn | 0.101 | 0.240 | KMeans-bad but linear-probe at parity |
| raw ST alone | 0.046 | - | baseline floor |

**5x lift** over raw ST. Aligned space organizes niches by transcriptomic tissue state at a resolution that unimodal ST cannot reach.

**R4's KMeans failure is geometry, not biology absence.** R4 compresses into ~3 effective dimensions. KMeans needs globular clusters. You cannot fit 14 globular clusters in 3 dims. But a linear probe (which only needs linear separability) recovers R4 to parity with R1. The biology is encoded as directions, not blobs.

### part B - compartment contrasts

> **open**: `runs/tnbc-92/eval/figures/cameron_review/h2_compartment_contrasts.png`

The proposal predicted: tumor, TLS, necrosis will show higher within-compartment matched-pair cosine than TIL stroma.

**Result: TLS passes. Tumor and Necrosis invert.**

- TLS vs TIL-stroma: z = +2.2 to +5.9 across R1/R2/R5/R6/B2. The organized lymphoid aggregates in TLS have a distinctive signature in both modalities.
- Tumor vs TIL-stroma: z = -8 to -15. **Inverts decisively.**
- Necrosis vs TIL-stroma: inverts in most runs. R3 (Barlow Twins) uniquely passes.

**Why the inversion**: Tumor (n=4,384 niches) and Necrosis (n=1,178) are large heterogeneous annotation classes pooling sub-types. High-TIL stroma (n=105) and Low-TIL stroma (n=354) are small, well-curated, homogeneous annotations. Within-compartment cosine measures annotation purity, not morphological distinctness. The small curated annotations are more internally coherent than the large pooled ones. This is an annotation-vocabulary limitation.

### part B.2 - TLS gene signature (a surprising finding)

A continuous TLS gene-signature score (from ST counts) was tested against z_he (from H&E) using cross-patient CCA.

| run | z_TLS | passes? |
|---|---|---|
| **B4 random-init** | **25.5** | **yes (strongest!)** |
| B1 CCA | 16.6 | yes |
| R4 cross-attn | 11.4 | yes |
| B2/B3 classical | 11.3 | yes |
| R5 AnInfoNCE | 2.4 | marginal |
| R1/R2/R3/R6 late-fusion | < 1.6 | **no** |

**The interpretation**: TLS is directly decodable from raw Virchow2 features. Organized lymphoid aggregates have a distinctive morphological appearance that Virchow2 captures without any alignment training. A random-init MLP preserves this signal; contrastive late-fusion training *degrades* it while gaining cross-modal coupling.

**The lesson**: contrastive alignment is not free. It trades single-modality decodability for cross-modal coupling. For signals already well-encoded by the foundation model (like TLS morphology), alignment can actually hurt.

### part C - biology vs patient identity

| run | bio/patient ratio | interpretation |
|---|---|---|
| R6 | 0.547 | biology dominates |
| R5 | 0.497 | biology dominates |
| R1 | 0.461 | biology dominates |
| R4 | 0.376 | biology dominates (lowest patient z in grid) |
| raw_he floor | 0.137 | - |
| **B1 CCA** | **0.071** | **patient dominates (anti-helpful)** |

All 6 contrastive runs encode biology more strongly than patient identity. B1 CCA amplifies patient identity 3.3x over raw H&E. **B1 should never be used for cohort-level biology interpretation.**

## 6. H3 - does it transfer across patients?

### the within-cohort test is worthless for comparison

Fit CCA on all test niches, ask if pathway signal exists. **Every run passes (all 120 cells BH-FDR < 0.001).** With 512 dimensions and 35,594 niches, you can always find a 1d direction that correlates with a 1d target. The within-cohort test confirms the hypothesis is trivially true but does not discriminate between methods.

### the cross-patient test is what matters

Fit CCA on 11 of 14 test patients, evaluate on 3 held-out. 500 permutations, BH-FDR < 0.05. 4 testable pathways (TGF-beta underpowered at set_size=2, excluded from FDR family).

| run | Immune | ECM | Cell Cycle | PCD | sig /4 |
|---|---|---|---|---|---|
| **R4** | **25.4** | **16.0** | **16.5** | **11.2** | **4/4** |
| B1 CCA | 15.2 | 10.4 | 9.8 | 7.5 | 4/4 |
| B2/B3 | 17.1 | 9.2 | 10.4 | 6.7 | 4/4 |
| R5 | -1.9 | 3.0 | 2.1 | 3.0 | 2/4 |
| R1 | 2.7 | 1.5 | 1.5 | -0.6 | 1/4 |
| R3 | 2.3 | 0.1 | 0.7 | 0.2 | 1/4 |
| R6 | 0.5 | 1.3 | -1.8 | 0.6 | 0/4 |
| R2 | -1.6 | -2.2 | -1.5 | -1.2 | 0/4 |

R4 wins all 4 pathways with z-scores 11-25. Classical baselines also win 4/4 but with lower magnitude. Late-fusion contrastive runs mostly fail (0-2/4). The pathway signal they encode within-cohort is patient-specific and does not transfer.

### the aliasing mechanism - how R4 wins

R4's 5 named pathways project onto roughly the same direction in the shared space (off-diagonal pairwise cosine = 0.75).

| run | off-diagonal cosine | what it means |
|---|---|---|
| R4 | 0.75 | 5 pathways collapse to ~1 direction (aliased) |
| R1 | 0.48 | partial separation |
| B2/B3 | 0.38 | most distinct per-pathway axes |

**Why aliasing helps**: one robust biology axis is harder to overfit to patient identity than five distinct per-pathway directions. R4's cross-attention compresses the manifold and forces all correlated Reactome pathways onto a single transferable axis. That axis says "biologically active vs inactive" - it cannot distinguish *which* pathway is driving a niche.

**The trade-off is real**: for per-pathway resolution, you need B2 (Procrustes) despite its lower z-scores. R4 gives you cross-patient magnitude; B2 gives you per-pathway distinguishability.

### DAG-resolution decomposition (v1 - v3 deferred)

At the 395-node Reactome DAG resolution (sub-pathways), R4's top hits are biologically interpretable:

| sub-pathway | z-score | Reactome parent | Cameron: biology check |
|---|---|---|---|
| Co-inhibition by BTLA | 6.92 | Immune System | checkpoint receptor on T/B/NK cells |
| IL receptor SHC signaling | 6.80 | Immune System | cytokine signaling downstream of IL receptors |
| Integrin cell surface interactions | 6.21 | ECM Organization | cell-ECM adhesion, migration |
| ECM proteoglycans | 5.73 | ECM Organization | structural ECM components |
| Regulation of IFNA/IFNB signaling | 5.71 | Immune System | type I interferon regulation |
| Degradation of ECM | 5.47 | ECM Organization | matrix remodeling |

At this resolution, R4 *does* distinguish immune checkpoint biology (BTLA, IFN regulation) from ECM biology (collagen, proteoglycans). The 5-parent aliasing was a coarse-aggregation artifact - at sub-pathway resolution, R4 separates mechanisms within the Immune and ECM parent categories.

Classical baselines (B1/B2) are competitive at DAG resolution (70-74% sig rate vs R4's 79%). This is an honest finding - the R4 advantage narrows when you decompose to sub-pathways.

## 7. the routing table - no single winner

This is the core deliverable. Different biological questions require different alignment strategies.

| biological question | best method | why | H1/H2/H3 evidence |
|---|---|---|---|
| retrieve matched ST niche from H&E | **R4** | best cross-modal coupling | H1: AUC 0.859, CKA 0.631 |
| group niches into TME regions | **R5/R6/R1** | globular manifold supports clustering | H2: KMeans ARI 0.234-0.246 |
| transfer pathway signal to new patients | **R4** | aliased axis generalizes | H3: 4/4 pathways, z 11-25 |
| distinguish *which* pathway drives a niche | **B2** | lowest off-diagonal aliasing | H3: per-pathway axes preserved |
| minimize patient-identity leakage | **R6** | highest bio/patient ratio | H2-C: ratio 0.547 |
| decode TLS from H&E alone | **B4/B1** | TLS already in Virchow2 | H2-B.2: z_TLS 25.5 |
| **avoid for cohort-level biology** | **B1 CCA** | amplifies patient identity 3.3x | H2-C: ratio 0.071 |

This routing table is what the omicstra MCP agent will encode as task-conditional dispatch.

### locked decisions (amended 2026-06-01)

Three evaluation pivots from the proposal were made during execution. These were honest mistakes in the original proposal - the archetype label granularity, the 9-class dimension, and the R@1 stopping threshold were written before we fully understood the data structure. We went with the practical corrections that the evidence demanded. All three are now formally locked and PLAN_RULES.md has been amended.

| pivot | what changed | why |
|---|---|---|
| H2 Part A label | archetype (9-class, patient-level) -> mc_megacluster (14-class, niche-level NMF) | archetype has NMI = 0.89 with patient_id. every niche in a patient inherits one archetype. ARI on archetype is patient classification in disguise. mc_megacluster is the audit-correct niche-resolution biology label. |
| H1 primary metric | R@1 (absolute retrieval) -> AUC (ranking quality) | at 35k+ test niches cross-patient, absolute R@1 is ~10^-4 for all methods. the proposal's 0.1 stopping threshold was set before evaluation scale was known. AUC correctly measures whether alignment orders matched pairs above mismatched pairs. |
| H3 headline test | within-cohort CCA (Part A) -> cross-patient sub-split CCA (Part B) | within-cohort is universally positive for all runs (trivially true at 512d with 35k niches). cross-patient sub-split is the discriminating test that separates transferable from patient-overfit pathway encodings. |

### questions for Allison and Cameron

These came up during the evaluation and need biology input from both. Nasim's working assessment is included - please challenge or confirm.

**1. BTLA co-inhibition as top DAG hit (z = 6.92)**

BTLA-HVEM is a co-inhibitory checkpoint axis in the same family as PD-1/PD-L1 and CTLA-4. It's the strongest cross-patient transferable sub-pathway in the Immune System parent. Working assessment: **expected.** TNBC is the breast cancer subtype where immunotherapy works because the TME is immunologically active. Checkpoint signaling at the tumor-immune interface is mechanistically conserved across patients - different patients have different immune compositions but the same checkpoint machinery. Spatially, BTLA-HVEM interactions happen at the physical boundary between immune infiltrates and tumor nests, which is exactly what the niche unit captures at 200um spacing. BTLA is less studied than PD-1/CTLA-4 in TNBC and is emerging as a resistance mechanism in patients who progress on anti-PD-1. The MCP agent should flag BTLA hits as validated, not hypothesis-generating. Cameron/Allison: does this framing hold?

**2. Tumor/Necrosis compartment inversion (5/6 contrasts fail)**

Working assessment: **annotation-vocabulary limitation, not fixable for this paper.** Sub-typing Tumor by molecular subtype (BL/M/IM/MSL/LAR) would tighten within-compartment cosine, but Wang's subtypes are assigned per-patient on global pseudobulk. "BL Tumor spots" = "all tumor spots from patients classified as BL" - this reintroduces patient-level confounding through a different door. The real fix (spot-level morphological sub-typing via Virchow2 classifier) is a separate study. Recommendation: document as limitation, do not attempt before MCP build. Cameron: agree, or is there a faster path?

**3. R6 novae-only success on H2 (ARI 0.244, second best)**

Working assessment: **biologically expected.** The TME is fundamentally spatial. Immune-hot regions are immune-hot because immune cells physically cluster near tumor margins. A spatial GNN like Novae learns "what does this spot's neighborhood look like in expression space" through message-passing - that IS the TME state, by construction. gpath2vec adds mechanistic specificity (which pathway) but not TME state classification power. Good news for the MCP package: the ST side can operate in lightweight mode (Novae only) for basic TME routing without the full gpath2vec pipeline. Cameron: do you buy that spatial neighborhood structure alone is sufficient for niche-level TME classification, or could Novae be acting as a proxy for something else (e.g., library size gradients)?

**4. TGF-beta underpowered (set_size = 2 DAG nodes)**

Working assessment: **use R-HSA-9006936 (Signaling by TGF-beta family members) instead of R-HSA-170834 (Signaling by TGF-beta Receptor Complex) for the v3 DAG rerun.** The broader parent captures the full TGF-beta superfamily including BMP and Activin branches relevant to TNBC EMT and immune evasion. Alternatively, MSigDB HALLMARK_TGF_BETA_SIGNALING (54 genes) as a standalone robustness check. Cameron: do you have a preferred TGF-beta set, or is the broader Reactome parent sufficient?

## appendix: one-paragraph summary (for meeting invite)

omicstra aligns H&E histopathology and spatial transcriptomics embeddings into a shared representation space using contrastive learning on 92 TNBC patients. We tested 10 alignment strategies across three hypotheses: cross-modal retrieval (H1), structural biology preservation (H2), and cross-patient pathway transfer (H3). No single method wins everything. Cross-attention (R4) dominates retrieval and pathway transfer but sacrifices cluster geometry. Late-fusion contrastive runs (R1/R5/R6) win niche-level biology clustering but fail cross-patient pathway transfer. This task-conditional routing table is the core deliverable that the omicstra MCP agent will encode. Phase 1 (scientific validation) is complete; phase 2 (generalizable MCP package) is next.
